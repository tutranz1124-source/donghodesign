# Đông Hòa Property - Landing Page & Admin CMS

A production-ready luxury real estate landing page and lightweight visual admin CMS built with Next.js 14 (App Router), TypeScript, Tailwind CSS, and Framer Motion.

## 🚀 Live Features
- **Landing Page**: 100% faithful to the Figma design (`ĐÔNG HÒA PROPERTY`).
- **Visual Page Builder** (`/admin/pages`): Drag-and-drop block reordering, 1-click toggle, live modal block editor, multi-device preview (Desktop, Tablet, Mobile).
- **Media Library** (`/admin/media`): Upload, preview, replace, and delete images with lightweight decoupled metadata.
- **Blog Manager** (`/admin/blog`): Create, edit, draft, publish, and delete blog posts with structured formatting.
- **Customer Inquiries CRM** (`/admin/inquiries`): Real-time tracking of consultation requests.

## 🛠️ Deploy to Vercel

### Option 1: Vercel CLI
```bash
npx vercel
```

### Option 2: GitHub Repository
1. Push this repository to GitHub.
2. Import the repository into [Vercel](https://vercel.com/new).
3. Set Framework to **Next.js** and click **Deploy**.
